# 词间 WordCraft

面向中职英语课堂的班级、学生、词库、学习任务、测评与报告管理应用。Next.js 16 + React 19 + TypeScript + Drizzle + PostgreSQL，可本地开发并部署到 Vercel，数据库支持 Neon。

## 本地启动

1. `npm ci`
2. 复制 `.env.example` 为 `.env.local` 并配置 PostgreSQL/Neon 和腾讯云凭据。
3. 本地 PostgreSQL 可运行 `docker compose up -d`；使用 Neon 则跳过。
4. `npm run db:migrate`
5. 可选：`npm run db:seed` 显式写入演示数据。
6. `npm run auth:bootstrap` 为当前 CLI 工作空间创建首次教师账号。
7. `npm run dev`，教师访问 http://localhost:3000/t，学生访问 http://localhost:3000/。

首次教师的随机密码保存在被 Git 忽略的 `outputs/teacher-login.txt`。教师登录后可修改密码、分配学生账号。所有环境均要求登录；不存在 localhost 身份旁路或默认生产密码。

## 角色与权限

教师管理本人工作空间的班级、学生、词库、任务及报告。学生只接收本人学习所需数据，只能提交本人进度和测评。服务器校验角色、工作空间、班级和学生归属，客户端不能通过修改 ID 切换身份。教师密码重置和本人修改密码会撤销全部旧会话。

教师登录 `/t/login`，后台 `/t`；学生登录 `/login`，学习首页 `/`。旧教师首页访问会自动跳转到 `/t`。错误角色无法在另一端登录或获取另一端数据。

`/teacher`、`/teacher/login`、`/teacher/billing` 兼容旧链接，永久跳转至对应 `/t` 地址。学生身份测试流程见 [STUDENT_TESTING.md](STUDENT_TESTING.md)，建议使用无痕窗口与教师会话隔离。

任务列表、词库详情、单词行和班级卡片均提供编辑入口，学生资料沿用行内编辑。已开始或有学习记录的任务锁定班级、词库及题型，但可修改名称、时间、达标线和重复测评设置。未开始且无记录的任务可调整结构，并通过「更新任务词表」刷新快照；词库或单词的编辑不会自动改写已发布任务。

任务可删除，采用软删除并从学生待办移除，不清理已学词、学习进度、测评成绩和发布快照。教师「已删除」列表及报告保留历史；学生在「词表 → 已学习」和「我的 → 学习记录」查看原有记录。删除后禁止继续提交该任务，无需新增数据库迁移。

学生「我的」包含今日新词/复习/有效时长、累计学习天数/打卡天数/掌握词数/时长、可选日期的打卡日历以及 7/30/90 天时长与词数趋势。按北京时间按日去重，完成测评自动打卡，也可学习后主动打卡。新增 `0004_uneven_corsair.sql` 保存独立学习事件和历史基线；已删除任务不影响统计。旧数据只能保留可确认的累计时长与掌握状态，不反推或补造过去每日数据、学习天数及打卡天数。统计口径可在页面展开查看。

班级注册码为六位数字和大写字母组合，不区分大小写，生成时避开 `0/O`、`1/I`，并通过数据库唯一约束防止重码。旧 24 位注册码和链接继续有效，关闭注册或时段限制同时作用于新旧码。迁移 `0005_swift_trauma.sql` 后执行 `npm run registration:shorten` 为旧入口补充短码；操作可重复运行，不替换原长码。新建入口直接生成六位码。

修改密码入口收为单行，跳转 `/account/password`，返回时回到「我的」。学习列表和任务内均有设置齿轮，自动播放默认开启；偏好按学生保存在当前设备浏览器，关闭后不影响手动播放与音频缓存。私密浏览或换设备时可能需要重新设置。

教师在「班级与学生 → 学生注册」选择班级及开放时间，复制注册链接发给学生；可随时关闭。学生只需填写姓名和至少 6 位密码；学号、登录账号收在「更多信息（可选）」中，可留空，账号支持邮箱。已填写的账号全局唯一、非空学号在同班唯一，空学号可并存。教师密码仍至少 12 位。

学生默认用姓名和密码登录。同班重名不合并记录，也不按密码猜选账号：教师在「班级与学生」编辑姓名，或通过该学生的「登录设置」指定独立账号，让学生切换「用登录账号登录」。跨班重名可输入班级注册码定位，关闭注册不影响原学生用该码定位登录。教师修改姓名同步登录账户，调整账号不必重置密码；学生 ID 和学习记录保持不变。

学生端使用「学习 / 词表 / 我的」底部导航。词表区分待学习、已学；账号资料和修改密码仅在「我的」。单词与题目随机排列，拼写练习补全缺失字母，听音题选择英文单词。

测评选择后立即判题；答对主题绿色高亮，停留 0.7 秒自动进入下一题，答错时错选标红、正确答案标绿，点击「下一题」继续。补全题填满缺失字母后自动判题；最后一题答对自动提交，保存失败保留重试入口。切到其他页面或浏览器后台时暂停自动切题。

补全题直接在单词缺失位置的横线上输入，不再使用单独输入框；支持连续输入自动跳空、方向键移动、退格返回上一空，以及粘贴缺失字母。

认词时可直接选择「不认识 / 模糊 / 认识」，无需先展开释义；点击后立即切词，进度在后台依次保存。失败保留原事件并提供重试，未保存完成时阻止返回任务和提交最终测评，刷新/关闭会提示可能丢失未保存记录。词表按任务创建时间（北京时间）分批、支持折叠；重复词保留首次分配批次，学习状态跨批次合并，删除任务仍保留已学词。

## 长词表与每日批次

1. 在「单词库」新建或打开词库，通过「导入 CSV」一次导入长词表（英文、中文释义必填，最多 5000 词，文件最多 2 MB）。
2. 点击「发布任务 → 自动分批」，选择词库和班级，设置每批 1–10 词、每天批次数、首日开始时间和每日截止时间。
3. 例如每批 10 词、每天 5 批，即每天最多 50 词；103 词自动排成 11 批、3 天，尾批 3 词。按词库的固定乱序拆分，同一词库、相同分批设置在各班级保持一致；已发布批次快照不随刷新、增词或编辑改变。批内测评出题仍可随机。
4. 学生「学习」按北京时间日期展示批次、当日词数和完成批数，未来日期默认折叠，可展开提前完成批次；每批独立缓存音频、学习和测评。词表按日期与批次查看。

整组发布使用事务和稳定计划 ID 防止重复提交；任务快照独立保存。每一批仍可编辑元信息或删除，已有学习历史保留；不允许将批次词表刷新为整本长词库。原「单个任务」模式保留用于已有工作流。

不再提供音序/乱序双方案选择，教师选择单一词库发布固定乱序计划。乱序由词库与单词稳定标识确定，与浏览器、日期、计划 ID 无关。历史双方案统一优先展示名称含「乱序」的路径，否则展示原主路径；原学习记录保留。

词库详情提供「删除词库」，需二次确认。删除采用软删除：词库及词汇从管理列表、后续发布选择中移除；已发布任务、词表快照、学习/测评记录和已生成音频保留，可继续学习。不会自动删除另一份真实词库。

学生词表每批的播放键依次播放整批单词（按显示顺序），播放键变为停止键并高亮当前单词；切换批次、单独点播、切换筛选或离开词表会取消旧队列。使用现有本地音频缓存，缺失音频沿用原生成权限和额度规则。学习页和教师词库例句中的当前词汇按完整词/短语、不区分大小写加粗，不解释或执行 HTML。

学生词表按批次时间从早到晚排列。已学词点播或整批连播完成后记录复习，复习每天按词去重；重复认词和再次完成测评也计入复习。「我的 → 学习趋势」包含每日复习词数折线图。完成练习有短暂庆祝动画，系统减少动态效果设置下停用。学生页面限制手势缩放和双击缩放，教师端不变；浏览器或系统的无障碍放大仍可能优先于网页限制。

## 单词发音

保存到桌面的 standalone 模式使用原生 HTMLAudioElement 播放本地缓存音频，不再依赖 Web Audio 的 resume；第一次点击同步解锁，切后台后清理旧播放器，返回后可点击发音或「开启声音」重新解锁。普通浏览器保持现有 Web Audio 路径。此适配仍需真实 iPhone 验证，不能保证修复所有 iOS 系统音频问题。

词表批次连播只使用当前可见单词：待学习跳过已学词，已学习只播已学词，搜索后只播匹配项；切筛选、搜索、数据更新或离开页面会停止旧队列。

练习中答错的词义、听音或拼写题会进入本轮队列末尾，直到答对才移出。测评正确率仍按每题第一次作答统计，纠错重做不会覆盖首次错误。练习布局使用可见视口高度，操作按钮固定在题卡外；小屏自动精简标题与关卡栏，拼写完成后收起键盘。

单词库每个词都有播放按钮。学生端和单词库共用服务端接口：已有 COS 音频直接复用，缺失时用腾讯 YunMia 403006 生成 MP3、上传私有 COS，记录数据库索引，再返回短期签名地址。并发生成通过数据库锁去重，Vercel 运行时不写本地磁盘。当前仅美音。Safari 支持 Audio Session 时会使用 playback 媒体会话，允许静音开关开启时发音；仍需非零媒体音量及首次点击解锁，旧版 Safari 无该接口时不保证静音播放。

进入学习任务时，先下载整组单词音频并存入浏览器 IndexedDB，完成后开始学习。后续点击与自动播放从本地缓存读取，不再逐次请求 COS；清除站点数据或更换设备后需重新缓存。浏览器禁止本地存储时退回内存缓存。首次学习和听音选词自动发音；浏览器拦截自动播放时点击「开启声音」。这不代表整个应用支持离线学习，进度及测评保存仍需联网。

批量预生成仍可使用：

```sh
npm run audio:plan
npm run audio:sync
npm run audio:validate
```

批处理读取 `PRONUNCIATION_WORD_SOURCE=database` 指定数据库的 CLI 工作空间。运行时按需生成不依赖静态 manifest，登录后可从 `/api/pronunciation/manifest` 查看本人的动态索引。详见 [AUDIO_SETUP.md](./AUDIO_SETUP.md)。

## 平台管理与测试额度

当前 `teacher` 账号为唯一最高管理员，后台 `/admin`。身份绑定数据库 ID，而不是前端参数或用户名匹配；数据库约束只允许一个管理员。普通教师由管理员创建，各自拥有独立课堂空间，不能查看其他教师数据或创建管理员。

- 教师管理：查看班级、学生、任务、完成人次和最近学习时间；新增、改名、停用教师登录。停用会撤销该教师会话，不删除其学生记录。
- 教师 `/t/billing`：查看本工作空间用量、点数和最近 50 条流水，输入兑换码增加点数。学生用量归属所在教师工作空间。
- 管理员兑换码：批量生成、设置点数/有效期、作废未使用码、查看兑换归属。完整码只在生成时返回一次，数据库仅存哈希；请及时下载保存。
- 余额使用虚拟「额度点数」，不是人民币资金。没有在线支付、自动续费或真实收款功能；管理员可手动调整并保留流水。
- **默认不启用扣额**。`/admin → 额度与单价` 可启用；仅缺失音频的新合成按字符扣点。已有 COS 文件、内置音频和缓存不扣合成点数。余额不足返回 402，不影响既有音频、学习记录及任务。原防滥用限流仍有效。

用量从本次上线开始记录：合成请求及获得有效响应的字符、服务端 COS HEAD/PUT/代理 GET 请求、文件体积和签名链接的下载估算。直接签名链接不能证明实际下载，未知大小不计入字节估算，内置静态音频由 Vercel 提供，历史/共享存储不能精确分摊。按当前配置单价估算，不是腾讯云账单；单价 0 显示未配置。失败调用可能已有云端成本，跨云上传/数据库故障无法提供严格的外部计费 exactly-once 保证。

现有 Neon 已执行 `0003_overjoyed_the_liberteens.sql`；其他环境上线前需迁移。新库先迁移再 `npm run auth:bootstrap`，会绑定名为 `teacher` 的教师为唯一管理员，不会替换已存在的管理员。

`test:billing` 默认读取本机忽略目录 `outputs/teacher-login.txt` 的管理员凭据；如已改密码，通过本地环境变量 `TEST_ADMIN_PASSWORD`（可选 `TEST_ADMIN_USERNAME`）提供当前凭据，不要提交密钥。该测试不更改全站计费设置。

## 验证与部署

```sh
npm run typecheck
npm run test:learning
npm run test:audio-cache
# 启动应用后，使用临时教师/兑换码测试，不开启全站扣额：
npm run test:billing
npm run lint
npm run build
npm run db:check
# 先启动应用，再运行真实 Neon/COS 集成测试：
npm run test:integration
```

Vercel 配置已指定新加坡函数区域 `sin1`，Node.js 使用 22.x。环境变量、数据库迁移、首次账号和操作说明见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

`npm run build` 不执行迁移或写入示例数据。请在受控发布步骤对目标数据库运行迁移，生产/预览推荐使用不同 Neon 分支。

## 数据

结构定义在 `db/schema.ts`，迁移文件在 `drizzle/`。登录会话、限流和音频索引持久化到 PostgreSQL，在多实例部署间共享。密码采用 scrypt，加盐保存；Cookie 使用 HttpOnly、SameSite=Lax 和生产 Secure。

现有演示课堂已保存到 Neon。原云端 D1 真实数据不会自动导入，需要独立导出并转换。
